## Overview

**Wedding Planner** is a refined marketing site for a wedding-planning studio. It opens on a romantic hero, reinforces credibility with a trust bar, then showcases services, a portfolio of real weddings, and transparent pricing — closing with testimonials and a contact section. Floating decorative elements add a tasteful, celebratory feel throughout.

## ✨ Highlights

- 💐 **Hero + trust bar** that sets tone and builds confidence immediately
- 🛎️ **Services** detailing full-service planning offerings
- 📸 **Portfolio** of past weddings and events
- 💰 **Pricing** tiers presented clearly
- ⭐ **Testimonials** and a **contact** section to capture enquiries
- ✨ **Floating decorative elements** and smooth, responsive design

## 🧱 Tech Stack

- **React 18 + TypeScript** on **Vite**
- **Tailwind-style utility CSS** with MUI + Radix UI primitives

## 🚀 Getting Started

```bash
npm install     # install dependencies
npm run dev     # start the dev server
npm run build   # production build
```

## 🗂️ Structure

```
src/app/
├── components/   # Navigation, Hero, TrustBar, Services, Portfolio, Pricing,
│                 # About, Testimonials, Contact, Footer, FloatingElements
└── App.tsx       # composes the page
```
